# Geometry Calculator (OOP)

A simple, well-structured Java application built to demonstrate core Object-Oriented Programming (OOP) concepts.

## Features
* Calculates the area of different geometric shapes (Circle, Triangle).
* Demonstrates **Inheritance** (using a `Shape` superclass) and **Polymorphism**.
* Clean and modular architecture.

## Technologies Used
* Java
* IntelliJ IDEA
